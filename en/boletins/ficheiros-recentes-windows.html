How to find recent files in Windows

Quickly find recently used documents and understand this list’s limitations.

By Calembe dos Santos2 min readUpdated Sep 16, 2026

January 2023 bulletin · revised

IN THIS ARTICLEUsing File ExplorerUsing the shortcut from the original bulletinWhat this list does not tell you

Using File Explorer

Press Windows + E and open File Explorer Home. Depending on your version and settings, you may see recent and recommended files. Microsoft describes Home as a starting point for accessing files on your computer and in the cloud.

Using the shortcut from the original bulletin

  1. Press Windows + R to open Run.
  2. Type recent and press Enter.
  3. Use the shortcuts shown to find documents recently used in the profile.

Some shortcuts may point to files that have been moved or no longer exist. The list may also be empty or incomplete, depending on settings and how applications are used.

What this list does not tell you

This tool helps you find documents. It is not a complete audit log and, on its own, it does not identify who opened a file. A document’s absence from the list does not prove it was never accessed.

If you are concerned about unauthorized access on a work computer, ask your IT team to review the available logs and policies. This article updates the original bulletin’s explanation, which presented the list as a way to see what someone else had accessed.
